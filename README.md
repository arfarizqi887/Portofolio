# Portofolio kelompok RPA

Website portofolio satu halaman dengan tema dark navy dan aksen biru neon atau ungu.

## Isi
- Navbar tetap, Hero dengan teks mengetik, About, Skills, Projects, dan Contact
- Responsif untuk desktop, tablet, dan ponsel
- Tanpa framework dan tanpa instalasi, hanya satu file `index.html`

## Menjalankan
Buka `index.html` di browser.

## Hosting dengan GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.

## Mengubah isi
- Nama: ubah `const NAME` di bagian `<script>` pada `index.html`
- Proyek: ubah array `P` di bagian `<script>`
- Email dan tautan sosial: cari `halo@contoh.com` dan `username` lalu ganti
